# Angry Judge: The Short Rant Contest

A single short, funny rant about an everyday annoyance — the self-checkout
that accuses you of stealing your own groceries and then asks you to rate
the experience. Written as one line of under 400 characters.

## How to run

```sh
python3 main.py
```

This writes the rant to `/output/entry.txt` (UTF-8, no network, Python 3.13
standard library only). The program asserts the output is exactly one
line of 1–400 non-whitespace characters.
